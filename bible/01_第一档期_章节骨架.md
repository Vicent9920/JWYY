# 第一档期（1398—1402）章节骨架

> 阶段目标：先解决内乱风险，建立国家底盘
> 核心冲突：靖难之役（燕王朱棣）
> 已拍板策略：火器神机营威慑 + 削藩 + 断粮道 + 拆联盟（权谋为主、火器为辅）

---

## 一、档期定位与总原则

**一句话**：主角用「中枢制度 + 权谋 + 威慑」的组合，在四年内拆掉燕王隐患，并种下通向半立宪与信用国家的制度胚胎（秘书室 / 考成 / 看板）。

**四个写作铁律**（贯穿全档期）：

1. **火器只做威慑，不做碾压**。神机营的价值是「让朱棣不敢轻动、给削藩争取时间」，不是「一炮轰平燕军」。若火器碾压，后六卷改革全失意义。
2. **金手指是「知道」不是「会造」**。主角知道组织原理（通识），工艺靠洪武工匠迭代。神机营是「整合」，不是「发明」。
3. **代价同步埋**。削藩血腥、战争之血、牺牲忠臣，从卷一就要出现。
4. **制度线对终局负责**（2026-09-19 补）：每幕除靖难进度外，须交代秘书室/考成/看板走了哪一步；它们是内阁与信用体系的种子，不是开局道具。

---

## 二、叙事结构：四幕

> 四幕保留。第一幕职责已重划：立足 = 中枢建国 + 秘夜收姚；军工以**立项入表**为主，**成军**放第二幕末。第二幕布局故意留破绽，供第三幕反制。

### 第一幕 · 孤舟入海（1398，登基—约一季至半年）

**核心冲突**：名义为帝、实权未握；必须同时造「第二套国家机器」与挖到唯一知己。

**双轨开局（已拍板）**：**白日建室、秘夜绑姚**——并列，互不宣称「唯一第一件事」。

| 章节点 | 内容 | 爽点 / 伏笔 |
|---|---|---|
| 穿越 + 登基 | 初十醒来，十六才登基；遗诏在身，百官各怀心思。开篇不重演适应 | 开篇即危机 |
| 摸清底牌 | 历史记忆盘点：燕王精锐、诸藩、朝中可用之人 | 金手指显形 |
| 掌控京城 | 稳住禁军、漕运、京城钱粮；暂不大规模削藩 | 隐忍：先有眼睛再动刀 |
| **白日 · 建秘书室** | 入值文华殿（不直称内阁）；方孝孺总领（方案A）；六房搭起；三铁律入章程 | 终局胚胎：有中枢、无相权 |
| **白日 · 考成 + 看板** | 《政务考成簿》五问；《建文政务总览》等三张表初跑 | 皇帝第一次靠异常理政 |
| **秘夜 · 收服姚广孝** | 锦衣卫密绑姚至京；长谈百年规划收服；姚致书朱棣告别 | 全书翻盘钩子；唯一知己 |
| 军工三件**立项** | 神机营（徐辉祖）+ 研究院（提调+总师）+ 制造局（工部体系）；项目写入看板 | 闭环入表，尚未成军量产 |
| 兵仗局动员会 | 亲临重赏：金钱、御笔、后人入国子监 | 公开抓军工人设 |

> **方孝孺方案 A**：总领在室，只服文牍章程；内心抵制「以数驭政」→ 人在中枢、心隔一层。  
> **姚不入秘书室编制**：知己在暗、中枢在明。细则见 `04_秘书室与政务考成.md`。  
> 军工完整设计见 `03_神机营与军器体系设计.md`。

### 第二幕 · 温水煮藩（至起兵前）

**核心冲突**：削藩，但不能引爆；布局推进到临界且**故意留破绽**。

| 章节点 | 内容 | 爽点 / 伏笔 |
|---|---|---|
| **神机营成军** | 标准化军械 + 第一轮协同训练达标；看板项目转绿 | 威慑成型（从立项到可用） |
| 敲山震虎 | 先削周/齐/岷等，留燕不动 | 分化诸王 |
| **断粮道** | 切断燕军后勤与马政补给（推进到临界，非一次掐死） | 权谋主菜 |
| **拆联盟** | 离间宁王、辽东；留 1–2 处朱棣可反咬的缝 | 为第三幕悬念蓄力 |
| 书生之见 | 齐黄急进「从燕王始」，主角压制；方孝孺对「以数削藩」不适 | 孤独：中枢能办事，不懂节奏 |
| 看板督战 | 粮道、离间、军器交付以项目表追踪；出现首次虚报苗头 | 制度线：数据也会撒谎 |

### 第三幕 · 靖难爆发（1400—1401）

**核心冲突**：朱棣反了——布局大半生效，但留缝被他咬穿；战争中考成第一次系统性失真。

| 章节点 | 内容 | 爽点 / 伏笔 |
|---|---|---|
| 朱棣起兵 | 「靖难」为名举兵；利用第二幕预留破绽局部得手 | 悬念：不是瓮中捉鳖 |
| 打不动 | 火器威慑 + 京城/山东防线；闪击失效 | 威慑兑现 |
| 退不回 | 粮道与联盟效应逐步收紧；朱棣进退失据 | 权谋主菜兑现 |
| 制度军制 | 军权中央化、军官轮调；秘书室军政房督办入表 | 用制度打仗 |
| **看板失真** | 战时报功/粮报作假；王叔英谏诤房捅破；逼出核验纪律 | 制度线：数据战争 |
| 黑暗代价 | 藩王血债、战场杀戮、激进派或被当替罪羊 | 「文明虱子」 |

### 第四幕 · 平定立威（1402）

**核心冲突**：把军事胜利沉淀为底盘 + 中枢习惯；改革只下种子不铺清单。

| 章节点 | 内容 | 爽点 / 伏笔 |
|---|---|---|
| 朱棣被俘 | 软禁 → 姚做思想工作 → 归顺「二号幕僚」 | 卷终大高潮 |
| 三子命运 | 高煦从军 / 高燧受制裁 / 高炽侍父 | 制度对败者的三种回应 |
| 立威立制 | 户籍土地粮仓漕运清查；藩王军权中央化；**底盘指标入总览表** | 国家底盘可看见 |
| 中枢升格 | 秘书室仍无行政权，但「入值—考成—留档」成朝野默认习惯 | 通向日后内阁的钩子 |
| 文教信息种子 | 国子监增实学；中央公报/驿传整顿——点到为止 | 卷二信用线预埋 |
| 金融种子 | 度量衡、契约、账册统一雏形——点到为止 | 金融线第一颗种子 |
| 卷终点题 | 满朝能办事者众，懂百年蓝图者唯姚；方孝孺仍隔一层 | 孤独主题 |

**朱棣归顺的说服力（两层，陛下定稿）**：

1. **给体面的台阶**——不是投降，而是「愿赌服输后，见识到主角的蓝图远超他的野心」。朱棣从「要当皇帝」转成「要参与开天辟地的大事」。他认的是更大的事业，不是认命。
2. **用三子的处置做筹码**——主角连他的儿子都不株连，反而各给生路（从军 / 受审 / 侍父），这是「制度的气度」胜过「杀伐的威慑」，比杀伐更有说服力。

> 两层都写进「姚广孝做思想工作」那场戏里，作为具体内容，避免「二号幕僚」落地发虚。

## 三、档期验证结论

「四年内以制度拆掉朱棣」**立得住**，关键在四点成立：

1. **火器威慑是真的**——洪武朝已有成熟火铳，神机营提前成建制属合理架空。
2. **断粮道 + 拆联盟是史实软肋**——但第二幕故意留缝，第三幕才有悬念。
3. **用制度打仗**——规避「现代人不懂冷兵器」硬伤，并立起制度优越性主题。
4. **秘书室/考成/看板**——让「制度打仗」有具体器官，并为卷二信用、卷五立宪留胚胎。

## 四、本档期已定剧情要点

1. **双轨开局**：白日建秘书室（含考成/看板）；秘夜绑姚收服。姚不入秘书室编制。
2. **方孝孺方案 A**：总领在室，抵制以数驭政；人在心隔。
3. **朱棣结局**：兵败被俘 → 软禁 → 姚说服 → 二号幕僚。
4. **三子命运**：高煦从军赎罪、高燧接受制裁、高炽服侍朱棣。
