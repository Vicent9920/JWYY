## 主角阵营

### 朱允炆（主角 · 穿越者）

| 项 | 内容 |
|---|---|
| 身份 | 大明建文帝，穿越者；穿越前是**资深高中物理老师 + 历史爱好者** |
| 年龄 | 1398 年 21 岁 |
| 金手指 | 历史走向记忆（**爱好者级·碎片**，知大概、不知细节）+ 通识原理（无图纸、无系统） |
| 性格 | 外仁弱、内隐忍；孤独、有百年愿景但前期无人懂；**开篇刚执政的茫然、错愕、硬撑** |
| 功能 | 掌舵人：全书唯一知道「终点在哪」的人 |
| 弧线 | 前期孤独寂寞 + 硬撑 → 后期被教育与社会发展逐渐理解 |
| 代价 | 亲手催生金融资本却目睹其剥削；为稳局做黑暗决策；被制度「淘汰」的孤独 |

**设定要点**：他最大的困境不是「不会」，而是「没人信」。他知道火器集中使用、标准化、复式记账、央行这些概念，但满朝文武只当他异想天开。所以第一卷的核心戏剧张力不是「敌人多强」，而是「全世界只有姚广孝信他」——秘书室能办事，却大多不懂百年蓝图。

**身份锚点（物理老师 + 历史爱好者 · 开篇基调）**：他教了半辈子物理，会的是原理、逻辑、用数字说话；不会的是朝堂、兵事、当皇帝。对明史是业余爱好者的模糊记忆——知道燕王会反、知道靖难、知道建文下落不明，却不记得具体年份、战法和败因。所以开篇他「**知道结局却无力改变、刚上手却完全不会干**」，满心错愕、惶恐、硬撑。他的本能武器是「要数、对数、用账说话」——这是物理老师的职业惯性，也是全书「以数驭政」的起点。**写作纪律：开篇不写上帝视角，不写老练盘算，只写真不会、真害怕、真硬撑。**

### 姚广孝（道衍和尚 · 军师 / 知己）

| 项 | 内容 |
|---|---|
| 身份 | 和尚，历史上前半生是朱棣谋主 |
| 年龄 | 1398 年约 64 岁 |
| 立场 | 架空翻转：被主角收服，成为谋主与唯一知己 |
| 功能 | ① 最懂朱棣的人，替主角拆解燕王；② 唯一理解主角百年蓝图的人，孤独的第一剂解药；③ 后期做通朱棣思想工作，使其归顺 |
| 弧线 | 从「谁都不信的书生」到「认定主角是天命之人」 |

**设定要点（全书最关键翻转 · 陛下定稿）**：与「白日建秘书室」**并列**——**秘夜绑姚**。锦衣卫密赴北平押至京师，长谈哲学、谋略与百年规划后收服；姚致书朱棣告别，转身为主角奔走。倒戈原因：一眼看穿「不是建文」，且被「制度立国、非人治」的蓝图震撼。

> 收服后第一公开动作：协助推动军器研究院 + 制造局（见骨架 / `03`）。姚**不入**秘书室编制——知己在暗处，中枢在明处，两套力量分开，避免「姚一来秘书室变影子内阁」。
