# 建文演义 · InkOS 创作简报（v0）

> 用途：供 `inkos book create --title "建文演义" --brief brief/inkos-brief.md` 使用。  
> 权威细节仍以 `bible/` 下文件为准；本文件是合并压缩版。

## 一句话

现代人穿成朱允炆，登基当日开局；用约五十年在位期把大明从军事帝国推向商业—工业帝国，并搭好半立宪框架，留最后一步给太子。

## 产品参数

- 平台：起点中文网
- 单章：4000+ 字
- 卷制：**方案 B · 六卷**（详见 `outline/volume-structure.md`）
- 卷一：约 **100 章**；四幕 **28 / 28 / 28 / 16**（详见 `outline/volume-01.md`）

## 核心决策（不可改，除非作者明示）

- 政体终点：半立宪（君主保留军队统帅权 + 一票否决；立法/司法分立）
- 生命周期：1398—1447 在位，1447—1457 太上皇，1457 去世；尾声至 1500
- 靖难：火器神机营威慑 + 削藩 + 断粮道 + 拆联盟（权谋为主、火器为辅）
- 金手指：历史记忆 + 通识原理；无图纸、无系统
- 代价线：①文明黑暗面（资本剥削等）②孤独（前期几乎无人理解）
- 姚广孝：与建秘书室并列——白日建室、秘夜绑姚；不入秘书室编制
- 方孝孺：方案 A——总领在室，抵制以数驭政，人在心隔
- 朱棣：兵败→软禁→姚广孝说服→归顺为二号幕僚；三子三种出路
- 卷一终点：平定立威 / 朱棣归顺（整场靖难写完，不在开战前切卷）
- 开局中枢：秘书室（无行政权）+《政务考成簿》+《建文政务总览》三张表 → 内阁/信用/立宪胚胎

## 六卷速览

1. 1398–1402 靖难收燕王  
2. 1402–1410 信息与信用  
3. 1410–1420 扩张 + 金融启蒙  
4. 1420–1440 工业与资本互促  
5. 1440–1457 最后一搏 + 退位/太上皇  
6. 1457–1500 尾声立宪完成  

## 卷一（1398—1402）四幕

1. 孤舟入海：登基、收服姚广孝、军器院+制造局、徐辉祖组神机营
2. 温水煮藩：削弱藩、断燕粮道、拆宁王联盟
3. 靖难爆发：威慑+防线，制度军制落地，埋血腥代价
4. 平定立威：收朱棣、立国家底盘、金融种子、孤独点题

## 写作铁律

1. 火器只做威慑，不做碾压
2. 金手指是「知道」不是「会造」；神机营是整合不是发明
3. 代价从卷一同步埋
4. 现代词必须本土化（议政院、《大明宪章》等，见总纲词汇表）

## 文风（已定）

- 文体：酒徒《明》后期「百人队」卡。不用早期「炉火」第三人称参数。
- 人称：第一人称限知，「我」= 朱允炆。
- 权威：`bible/文风.md` 与 `style/bai-rendui/style_card.yaml`
- 硬约束：对话不独立成行；单句不超过 40 字；禁因此/然而/于是/总之；禁明喻、对偶、心理直陈、段末升华。
- 章长 4000+ 与句长限制不矛盾。
- 不写 KPI、Dashboard、系统面板；用已定本土词。
