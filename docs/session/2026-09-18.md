## 新小说项目立项讨论：朱允炆穿越改革流（暂定名待定）

**题材定位**：穿越流架空历史 + 种田/经营流。主角于 1398 年朱元璋驾崩当日穿越至朱允炆身上，
开篇节点为**登基当日**（1398 年 6 月 30 日 / 闰五月十六）。主线为大明治世改革，从军事帝国升级为商业—工业帝国。

**陛下提供的改革总纲**：7 个十年档期（1398—1500），横跨 7 条并行线：
军事+扩张 / 财政经济 / 政治制度 / 科技 / 文化教育 / 信息舆论 / 金融资本市场。

| 档期 | 阶段目标 |
|---|---|
| 1398—1402 | 先解决内乱风险，建立国家底盘 |
| 1402—1410 | 国家开始拥有可靠的信息与信用体系 |
| 1410—1420 | 第一次扩张 + 金融启蒙 |
| 1420—1440 | 工业与资本开始互相促进 |
| 1440—1460 | 形成成熟的前工业金融体系 |
| 1460—1480 | 帝国从军事国家升级为商业—工业国家 |
| 1480—1500 | 国家脱离皇帝个人能力也能运行 |

**阿衡的初步结构判断（待陛下拍板）**：
1. **时间跨度 vs 主角寿命是最大结构炸弹**。朱允炆生于 1377，到 1500 年 = 123 岁。
   → 三条出路：压缩时间轴（推荐）/ 多代接力换视角 / 加长寿系统设定。
2. 该表性质 = **改革总路线图（锚），不是章纲**。地位类比《最后一个变量》的"方案B四条线索"。
3. 七条线不是并列而是**有依赖顺序**：军事稳盘 → 财政清账 → 信息与信用 → 金融工具 → 工业资本互促。
4. **金融线是真正的差异化卖点**（票据—仓单—合股—转让所—期货—保险—央行这条链，历史网文极少有人写）。
5. 待定问题清单：靖难之役要不要打/怎么打（史实上神机营立于永乐年间，需前置合理化）；
   金手指强度（通史常识 vs 完整图纸）；主角的代价线与分阶段对手（勋贵/江南士绅/藩王/文官道统派）。
6. "登基当日开篇"的技术处理建议：把上升感从**权位**转移到**掌控力**（名义为帝、实为傀儡 → 第一卷就是夺权曲线）。

## 追加：陛下新增"宪制演化线"需求（Level 7/8 + 三权分立君主立宪）

陛下在原 7 档期表基础上，要求补入两级制度需求，终极目标是晚年把大明改成三权分立的君主立宪制：
- **Level 7**：反腐制度 → 官员财产公开 → 利益冲突制度 → 司法体系
- **Level 8**：政治制度化 → 权力制衡 → 地方自治 → 选举 → 司法独立 → 三权分立君主立宪

**阿衡给出的调整方案（已同步给陛下，待其拍板）**：
把反腐/司法/宪制内容拆成一条独立的"宪制演化副线"，L1→L8 阶梯映射到七个档期（全程埋线、晚年收束，不堆晚年）：

| Level | 内容 | 落位档期 |
|---|---|---|
| L1 | 吏治·监察强化 | 1398—1402 |
| L2 | 官员财产公开 | 1402—1410 |
| L3 | 利益冲突制度 | 1402—1410 |
| L4 | 司法体系独立 | 1410—1420 |
| L5 | 政治制度化 | 1420—1440 |
| L6 | 权力制衡（与金融成熟共振） | 1440—1460 |
| L7 | 地方自治 | 1460—1480 |
| L8 | 三权分立·君主立宪 | 1480—1500 |

**核心洞察（本书政治线的灵魂）**：
1. 金融线 × 宪制线是同一枚硬币两面——资本要求规则，规则要求限权，限权通向宪制。L6 权力制衡必须与 1440—1480 金融成熟期同步发生，而非两件独立的事。
2. 立宪的动机锚 = "用制度锁死皇权，防朱家后世出败家子"。主角让权不是自掘坟墓，而是造一台"不依赖任何个人也能运行"的机器，与原表末档"国家脱离皇帝个人能力也能运行"完美闭环。
3. 三权分立的大明翻译：立法=议政院/大议会；行政=责任内阁；司法=三法司（都察院/大理寺/刑部）独立化。宪法载体可用《大明宪章》。"选举"一词需本土化（科举选官→议政院议员推举/乡绅推选），否则出戏。
