## 这十四章怎么讲

一条线串下来：他知道四年内燕王会反，所以不先拔刀。刀从两处伸过来——齐泰的《削藩七议》，徐增寿夜里送出去的信。他用三件不流血的事把刀压住：清账、清军、清器。清器清到一半，他去请那个会把刀设计出来的和尚。人在路上的那些天，南京不空转，每章都收掉上一章抛出的一件实物。

黄金三章是：

- **c01** 暗线露面。章末他自己说「让他来」。
- **c02** 削藩议到案，他不批，要三个数。
- **c03** 三本账当场对穿，路线说出口，然后问庆寿寺的和尚。

第四个真正的高潮不在 c04。c04 是火器这句话和人出发。姚广孝的长谈在 **c10**：八人 c04 出门，约一旬后 c07 才在北平带走他，再约一旬 c10 抵京。中间的 c05、c06、c08、c09 各收一件已经出场的东西，不是干等。

徐增寿是暗线反派，幕一这十四章里不杀。他是徐达幼子、徐辉祖的弟弟，在京掌兵。杀掉他，清军和神机营一起裂开。史实里的诛杀不提前。

姚广孝不写「我等了十六年」。人物卡定的是：他事先不知道会被留下。钩子改成他烧掉自己写了一半的信——信上算的是「新君必先削燕」。南京没先削，这半封信就作废了。若审核时仍要用「等了十六年」，等于改人物，不要在正文里先写。

「先办三件不流血的事」不是发誓三年不见血。幕二削周、齐、岷仍会动藩。这句话只管眼前：燕的刀今天不拔。

## c01 · 闰五月

- **时间**：十六，哭临到入夜。
- **本章动作**：他看清谁在给北平递消息，并决定让齐泰进来。
- **场**：
  1. 灵堂。不是穿越苏醒。六天前已经醒过，冠带、哭临他都会。记忆浮上来的是倒计时：按旧史，大约四年，燕王会南下。这句话他不对任何人说。
  2. 群臣哭临。齐泰的眼往北。黄子澄看他。方孝孺不在前排。徐辉祖站得直。徐增寿把哭声哭得很齐，手却干净。
  3. 夜里他去城外驿，不带仪仗。看见徐增寿把一封不像祭文的信交给北平使者。他不拿人。拿了，魏国公的弟弟、京营的将，当天就会裂。
  4. 回到殿里。北平奏疏和齐泰密奏同时送到。一封请安，不谈兵。一封要刀。
- **章末**：他说「不必拦，让他来」。
- **不写**：问时辰；「今早才醒」；点门点柴；当场宣读削藩。

## c02 · 让他来

- **时间**：十六夜至十七。
- **本章动作**：刀递到面上，他不批，改要三个数。
- **场**：
  1. 齐泰、黄子澄呈《削藩七议》，第一句就是自燕始。理由是燕最强，先削则诸王震。
  2. 他把北平那封请安的奏疏和这本七议压在一处，都不批。不跟他们争燕王会不会反。
  3. 他只要三个数：太仓储粮、在京军额、兵仗局同型火铳的实数。在场的人各说一个约数，三个约数彼此不像话。
  4. 限次日三衙把门籍、仓簿、器械簿送到，经手的主事亲自来，带算盘。齐泰以为数完就可以削。他不许这个诺。
- **章末**：值房外有徐增寿的人，在听哪三个衙门被点了名。
- **不写**：算盘当场打完（留给 c03）；召姚；方孝孺长篇反对（他可以在门外看见，话留到账拆开的时候）。

## c03 · 三本账

- **时间**：十七至十八。
- **本章动作**：账被当众拆穿，路线用一句话说死，然后把人指向北平的和尚。
- **场**：
  1. 三衙三套簿。六品主事拨算盘。太仓的文书和仓里的袋对不上，缺口不是零头。军额花名比点卯多。兵仗局册上的「在库」和架上的铳对不上。具体差额正文再写死一笔，章纲只锁「一眼能看见，不是尾数」。
  2. 方孝孺在场。他第一次不认同：这是商贾核账，不是帝王之道。人没走。
  3. 皇帝把《削藩七议》推开。说眼前只办三件不流血的事：清账、清军、清器。燕王的刀今天不拔。等这三件有数，再谈别的藩。不发誓三年都不见血。
  4. 散衙后他单独召锦衣卫，问北平庆寿寺有个唤作道衍的和尚，可知此人。
- **章末**：锦衣卫答知道，是燕王身边的僧。他说明日随他去兵仗局，夜里再谈这个僧怎么请来。
- **不写**：八人当天就到北平；把三铁律在这章写进纸。

## c04 · 十支铳

- **时间**：十八至二十。
- **本章动作**：火器的话当众说死，两路人同一夜出门。
- **场**：
  1. 亲临兵仗局。取十支登记为同型的手铳，十种口径，其中三支不发火。他不画图，不说自己会造。
  2. 落下纲领：一万支打得响的，不如五百支打得准的。徐辉祖在场，听的是以后这支试验的人由他领，任务是把能打响的收到一起操演，不是出征。本章不发营印，不称成军。
  3. 当众立三赏：银、御笔、荫子入监。按做成的物件和记下的失败领，不按磕头领。赏格立下，银子不在本章发完。齐泰想接制造的印，被拒，只许以后交需求。
  4. 夜里两道密令。八人北上庆寿寺，活着请道衍，不血洗，不惊动燕王府大队，往返按旬。另一拨只去记北平粮道和马市的数，不动手，这是幕二断粮的眼。
- **章末**：八人出城。他跟领队说，谁若回来说三日能打个来回，就是谎报。
- **不写**：姚已经感到有人来接；新枪；神机营成军。

## c05 · 送不出去的信

- **时间**：二十之后数日。八人在途，本章不切路。
- **本章动作**：徐增寿的第二条信落到案上。他仍不杀。
- **场**：
  1. 清军先清漏。北平使者的信袋改由锦衣卫查验，门籍换过。不公开说在防谁。
  2. 徐增寿再送一封。信没出城。里面没有「起兵」二字，有的是京营哪一日换防、哪座门谁值。
  3. 徐辉祖来问是不是要弟弟的命。皇帝说要的是营，不是这条命。徐辉祖不谢，也不替弟弟求饶。兄弟之间的缝留下。
  4. 他把这封信压在《削藩七议》下面。一封要他杀人，一封在给人送刀。
- **章末**：两封都不批。徐增寿还在京，还掌着兵。
- **不写**：廷杖、下狱、赐死；徐辉祖因此倒向燕。

## c06 · 执笔

- **时间**：约登基第十日前后。密令仍在途。
- **本章动作**：方孝孺把反对写进纸，又把三句限制一起写进去。
- **场**：
  1. 召方入值。对外的话是朝夕备顾问。方按侍讲来，先问读哪部书。
  2. 案上仍是三本对不上的账，加徐增寿那封信。皇帝让他写章程，不是写罪己。
  3. 方的草稿文辞完整。皇帝往里加三句：不得代六部行事；入值之后的奏报必须留档；不得只报喜。方写得下。写到留档，笔停过。
  4. 方问这是不是以数驭政。皇帝不跟这四个字打转。他说明日点人，奏报先入公档，不先入任何一只手。
- **章末**：笔在方手里，人还没点齐。
- **不写**：六房名单宣完；姚的行程细节。

## c07 · 庆寿寺

- **时间**：八人出门约一旬之后。与 c06 隔数日，不是次日。
- **本章动作**：道衍离寺，未服。南京只知道人已经离开。
- **场**：
  1. 切姚的限知。庆寿寺带走，不围燕王府，不血洗。朱棣当天不知道人已经不在。
  2. 姚看人数和带法。若是杀，不必八个人这么整齐，也不必留活口。他问谁下的令。对方只答：南京请僧，活着走。
  3. 他未服。案上有半封写给燕王的信，算的是新君登基后必先削燕。他把这半封烧掉。不是因为等了十六年，是这句已经被南京的做法打脸。灰留下。
  4. 切回南京。密报到值房外，只有「人已离寺」。皇帝对报信的人说：回来仍按旬算。
- **章末**：回程才开始。案上那三本账还在。
- **不写**：路上长谈；朱棣发兵找人；「我等了十六年」。

## c08 · 公档

- **时间**：姚在返程。京师。
- **本章动作**：入值的人点齐，消息不许从一只手里过。
- **场**：
  1. 点人。方孝孺总领。黄子澄政务，齐泰军政，练子宁考成，王叔英谏诤，解缙文书，陈迪外议。门口的名义仍是入值文华殿。
  2. 黄子澄要把章奏先过自己手。皇帝把部奏挡进公档。徐增寿那种信走锦衣卫留档，不进黄子澄的袖子。
  3. 齐泰又把《削藩七议》往前推。皇帝指军额那本书：军政房先把在京的数对完，条陈里这次不许出现燕字。
  4. 练子宁领走空白的考成式样，下一章才让六部试填。
- **章末**：墙上的名单没有姚广孝。人还在路上。
- **不写**：五问已经把六部问哭；总览每天呈上。

## c09 · 五问

- **时间**：返程将尽。
- **本章动作**：问法印出来，六部用空话接，人到了城外。
- **场**：
  1. 练子宁把五问写成《政务考成簿》：做什么、谁负责、何时完、怎样算完、未完的原因。拿 c03 那笔对不上的仓粮试填。
  2. 户部答「正在办理」。皇帝退回，让主事把算盘上的差再填进第五问。主事在，字仍不敢写满。
  3. 方孝孺说此法近商贾。他不拦退件，也不帮着填。人在，心隔着。
  4. 夜里：请僧的人到京城外，未进城，僧还活着。
- **章末**：他说明夜见，不走正门。
- **不写**：当夜就把百年谈完。

## c10 · 论百年

- **时间**：抵京当夜。这一章是前十四章的高潮，字数放宽。
- **本章动作**：姚确认这不是他打量过的那个建文，仍不要官。
- **场**：
  1. 城外接入偏殿。案上三样实物：三本账的抄件、十支铳的口径单、还没填的军器空行。不先讲哲学。
  2. 姚问为什么不先削燕。皇帝把未批的《削藩七议》推给他看，再说清军清到徐增寿的信为止、为什么那个人还活着：要营，不要那条命。
  3. 谈的核心只有一件：账、军、器必须离开他这张嘴还能核。不是今晚铺开立宪，不是教他造铳。火器和钱粮都只作为已经看见的失败样本。
  4. 姚要一夜，不要入值的位置。他服的是这件事比争位大，不是服一个官职。
- **章末**：他说徐增寿你不杀，我听懂了。听懂还不是留下。留下要看明天你怎么圈那张表。
- **不写**：告别信写完；姚的名字进名单；神机营怎么打赢燕军。

## c11 · 圈一格

- **时间**：抵京次日白、次夜。
- **本章动作**：表第一次只圈一处延期；信写出，未出京。
- **场**：
  1. 白天《建文政务总览》第一次呈上，空格很多。颂圣跳过。他只圈 c09 退回的那笔仓粮，问第五问为什么仍空着。
  2. 方说这是以数驭政。说完仍留在值房，不辞。
  3. 夜里姚写信给朱棣。读者看见态度：不是报被俘，是告诉他南京有一件比争位大的事，自己不再回去设计「先削燕则我们起兵」的旧局。全文不抄进正文。
  4. 信写完，在姚手里。
- **章末**：信未出京。姚说明天问自己站在哪里。
- **不写**：朱棣拆信。

## c12 · 名单

- **时间**：此后一两日。
- **本章动作**：信北上，人名不进殿。
- **场**：
  1. 信交暗路北上。本章不切北平，不写拆信。
  2. 姚问位置。皇帝说：不入文华殿名单，不挂任何一房，不见外朝班。夜可以来，昼没有他的椅子。
  3. 解缙把公示名单清一遍。有方孝孺等人，没有姚广孝。黄子澄若问夜里是谁，皇帝不答。
  4. 姚接受。他要的是能对着那三样实物说话的夜，不是一座衙门。
- **章末**：明处一份名单，暗处一个人。信在路上。
- **不写**：姚代六部批字；朱棣回信。

## c13 · 三行

- **时间**：名单公示后数日。
- **本章动作**：c04 看见的失败，写进表，并写成还没完成。
- **场**：
  1. 三行入项目表：试验营（徐辉祖领，不称已成军）、研究院（提调加一名没有爵的总师，试验必须记录）、制造局（大使管造，总检不归大使）。每行状态都是未成、未齐。
  2. 齐泰交《军器需求条陈》，不兼任何一印。他看见营在徐辉祖名下。
  3. 徐增寿的名字不在三行里，也不在值房名单里。他仍有京营的旧职，c05 没夺干净，这里不补一刀杀他，只确认他碰不到这三行。
  4. 有人拟「已有规模」。皇帝划掉。立项不许写成已成。
- **章末**：方把这张表归进文牍，不当它是政。姚夜里会看。本章可停在方把表合上。
- **不写**：阅兵成军；第一件不合格品的长戏（那是后一簇的事，c04 已经立过纲领）。

## c14 · 三样都不动

- **时间**：双轨收束这一日。仍在登基后一个多月内。
- **本章动作**：把读者从 c01 带到这里的三样东西再摆一次，一件都不提前用掉。
- **场**：
  1. 白天按五问再退一份「正在办理」，退件留档。王叔英指出有一房只把好听的送进总稿。皇帝让他记名，本章不申饬、不杀人。
  2. 夜，姚对坐。确认明处是中枢，暗处是谋主，两边不互相代替。
  3. 案上三样：未批的《削藩七议》、未成的军器三行、徐增寿那封换防的信。姚问哪样先动。皇帝说都不动。账还没核完，营还没练到一起，这封信的主人还不能杀。
  4. 窗外没有北平的烽火。告别信仍在路上，本章不写送到。
- **章末**：三样都还在案上。下一季才谈成军和削藩。燕未动。
- **不写**：起兵；读信后的朱棣；立宪；把徐增寿正法。

## 审核时请先定的三处

1. **黄金三章**用现在的切法：c01 撞见徐增寿并「让他来」，c02 不批要数，c03 算盘和路线。火器和请僧放在 c04。若你希望火器进入前三章，把 c03 与 c04 对调，账的爽点会后移一天。
2. **长谈在 c10**，不在 c04。这是为了保住旬计。若长谈必须紧贴出门的下一章，旬计就要改。
3. **徐增寿这十四章不杀**，暗线留到他真正把兵情送到燕军手里再处置。姚不写「等了十六年」，写烧掉半封「必先削燕」的信。

确认前不写正文。c15 以后的旧纲先不动，等这十四章定了再往后接。
